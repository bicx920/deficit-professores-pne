# Déficit de Professores e PNE

Projeto de análise de dados sobre a distribuição de professores da rede pública de ensino e sua relação com as metas estabelecidas pelo Plano Nacional de Educação (PNE).

## Objetivo

Analisar os dados disponíveis sobre os vínculos dos professores e investigar o cenário atual em relação às metas de valorização e efetivação dos profissionais da educação.

## Tecnologias

- Python
- Pandas
- Jupyter Notebook
- Excel
- SQL
- GitHub
